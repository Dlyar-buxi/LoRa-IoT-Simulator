# LoRa-IoT-Simulator v1.1.0

**Research Benchmark Release**

## Added

- Cross-platform local demo runner — `scripts/run_demo.py` (generates
  `demo.db` + `demo_report.md` headlessly, no Docker required).
- Opt-in Docker demo profile — `docker compose --profile demo up --build`.
  A one-shot `demo-init` service seeds a sample experiment on first launch.
- `## Quick Demo` guide in `README.md` — clone-and-run onboarding that needs
  zero code reading.

## Improved

- Benchmark reproducibility: a single unified entry point,
  `scripts/run_all_benchmarks.py`, runs all three experiments in order with
  consistent logging.
- Documentation consistency: fixed dead `run_demo.sh` references and aligned
  the documented demo parameters (20 nodes, 2 gateways, area 400, seed 1) with
  the command that actually runs.
- Demo isolation: demo data is volume-scoped in Docker (the `experiments-db`
  volume) and git-ignored locally (`demo.db`/`demo_report.md`), so it never
  touches the production `experiments.db`.

## Verified

- 20-node LoRa simulation with 2 gateways, seed 1, PDR 1.0.
- Benchmark regeneration end-to-end via `scripts/run_all_benchmarks.py`.
- Quick Demo both ways: Docker profile and local Python path.

## Frozen core (unchanged since Sprint 4)

`simulator/`, `gateway/`, and the `backend` engine are byte-for-byte
unchanged. Everything in v1.1.0 is additive: new `scripts/`, `docs/`, the
`README.md` showcase, and the `demo-init` Compose service only.
